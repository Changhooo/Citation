# CitationClaw Skills

The runtime splits the project into five phases:

1. `phase1_scholar_identify`: search paper A on the Scholar mirror and confirm the target.
2. `phase2_collect_citing_papers`: collect cited-by pages into paper group B.
3. `phase3_rank_authors_and_build_c`: detect Fellow/academician evidence and build C.
4. `phase4_pdf_context_extraction`: collect PDFs and extract citation contexts.
5. `phase5_sentiment_report`: label stance and export reports.
